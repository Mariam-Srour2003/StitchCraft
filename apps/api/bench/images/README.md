# Benchmark photos

Downscaled to 400 px wide copies of sample images from
[scikit-image](https://scikit-image.org/docs/stable/api/skimage.data.html), all free to reuse:

| File            | Subject                         | Licence                               |
| --------------- | ------------------------------- | ------------------------------------- |
| `chelsea.jpg`   | Cat                             | CC0, photographer Stefan van der Walt |
| `coffee.jpg`    | Cup of coffee                   | CC0, photographer Rachel Michetti     |
| `astronaut.jpg` | Astronaut Eileen Collins (NASA) | Public domain                         |
| `rocket.jpg`    | Falcon 9 launch (SpaceX)        | Public domain                         |

The gradient, logo and pixel-art images are drawn in code in `../sample-images.ts`.
